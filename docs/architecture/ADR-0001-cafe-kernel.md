# ADR-0001 — Cafe kernel on Guest-pro staff-scope

Status: accepted

Guest Premium’s GM / department-manager / personnel hierarchy is the management contract. DUA-OS-BE ports that rule engine as a pure domain (`staffscope`) parameterized by a vertical catalog.

Cafe is the first catalog. Hotel and supply catalogs are registered so a later workspace does not fork identity, membership or tasks.

Application services depend on small ports (ISP). Adapters (memory, postgres) implement those ports (DIP). HTTP handlers stay thin and split by surface (SRP). Verticals extend by adding a catalog (OCP).
